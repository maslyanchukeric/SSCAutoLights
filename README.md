# SSC Auto Lights

A production business website developed for **SSC Auto Lights**, an automotive company specializing in restored OEM automotive lighting and components.

The website was built to provide customers and automotive businesses with information about SSC Auto Lights' services and make it easy to contact the company.

## 🌐 Live Website

[Visit SSC Auto Lights]([(https://sscautolights20260925115304-eycjadhwd4hhgma6.westus3-01.azurewebsites.net/)])

## 🚗 About the Project

SSC Auto Lights is a professional business website built using ASP.NET Core MVC.

The website focuses on showcasing the company's services, explaining the OEM automotive components they work with, and providing customers with an easy way to contact the business.

This is a live production website developed and deployed for a real business.

## ✨ Features

- Responsive website design
- Professional business landing page
- OEM automotive component information
- Interactive "What We Buy" section
- Headlights
- Taillights
- Side Mirrors
- Front Radar Modules
- Blind Spot Modules
- Dynamic content using JavaScript
- Customer contact form
- Mobile-friendly navigation
- About and Contact pages

## 📁 Project Structure

The application follows the ASP.NET Core MVC architecture:

- **Controllers** — Handles application requests and page logic
- **Models** — Contains application data models
- **Views** — Razor pages used to build the user interface
- **wwwroot** — CSS, JavaScript, images, and other static files
